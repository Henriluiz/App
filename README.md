# ZenithApp
Zenith é uma plataforma onde conecta o paciente com o psicólogo de forma eficiente através de filtros. Versão do paciente no momento

Instale da seguinte forma, para não ter erro:
git pull
rm -rf node_modules
npm ci
npx expo start -c


Sempre que alguém adicionar dependência:
npx expo install <pacote>
